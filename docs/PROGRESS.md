当前源码/API 修订号 3 增加静息消耗估算与活动等级、文字/可选照片餐食 AI 草稿、膳食纤维/总糖/钠、部位训练模板、CSV/JSON 计划导入、单模板离线二维码和实际训练日期标记。健康 ZIP 新建为 v2，兼容导入 v1。

Linux Python 3.14 隔离环境排除 Windows 专属 `test_portable.py` 后 124 项通过、2 项跳过；Ruff、Svelte 检查和前端生产构建通过。完整 Linux 测试另有 5 项 Windows 启动器/注册表测试因系统 API 不存在而失败。Windows `scripts/check.ps1` 与新便携包尚未验收；上述功能不能视为已包含在 v0.4.0 成品中。

便携版无需Python、Node或Anaconda安装，使用Windows原生目录选择和无控制台EXE。依赖、前端与必要运行库完整包含，首次选择数据根目录后生成启动、停止、重启快捷方式。

自动检查为129项后端测试、Ruff及前端检查/构建；成品与浏览器检查均使用独立测试数据和模拟AI。具体结果和限制见[公开验收记录](ACCEPTANCE.md)。
