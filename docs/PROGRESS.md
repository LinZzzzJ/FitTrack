公开源码以一次干净的初始提交建立，不包含个人开发历史和运行数据。提供米白与深绿视觉风格的项目主页、模拟数据截图、中文使用说明和Windows便携包。

已包含账号隔离、身体测量、历史饮食、普通照片与营养标签、有氧估算、力量逐组记录、训练排期、趋势图表、AI目标、每日反馈及每周复盘、个人Key加密、受控数据目录、迁移和备份恢复。当前工作区新增静息消耗估算、文字餐食 AI、营养扩展、训练模板/文件交换/二维码和训练记录日历标记；这是未发布开发，不改变 v0.4.0 成品状态。

本轮新需求已实现源码和前端类型检查，API 修订号升至 3。Linux Python 3.14 隔离环境中，排除 `test_portable.py` 后 124 项测试通过、2 项 Windows 专属检查跳过；Ruff、Svelte 检查和生产构建通过。完整 Linux pytest 会有 5 项 Windows 启动器/注册表测试因平台 API 不存在而失败；Windows 基线 `scripts/check.ps1` 尚未执行，不能据此宣称 Windows 回归已通过。

便携版无需Python、Node或Anaconda安装，使用Windows原生目录选择和无控制台EXE。依赖、前端与必要运行库完整包含，首次选择数据根目录后生成启动、停止、重启快捷方式。

自动检查为129项后端测试、Ruff及前端检查/构建；成品与浏览器检查均使用独立测试数据和模拟AI。具体结果和限制见[公开验收记录](ACCEPTANCE.md)。
