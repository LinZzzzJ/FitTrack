FitTrack · 轻衡 v0.4.0
Windows 10 / Windows 11，64位 Intel 或 AMD 电脑

第一次使用，按以下步骤操作：

1. 右键 ZIP 压缩包，选择“全部解压”。将整个 FitTrack 文件夹放到固定位置，例如 D:\Apps\FitTrack。
   不要在压缩包内运行，也不要只拿出 FitTrack.exe；旁边的 _internal 文件夹必须保留。

2. 双击 FitTrack.exe。不需要安装 Python、Node、Anaconda，也不需要输入命令。

3. 在弹出的窗口里选择一个专用空文件夹保存数据，例如 D:\我的健身数据。
   这个目录由你决定。账号、照片、记录、加密Key、日志和备份都保存在这里。
   选择已有的有效 FitTrack 数据目录可以继续使用原数据。取消选择不会创建账号或密钥。

4. 程序会自动打开本机浏览器。在页面注册账号，填写个人身体资料。
   网页只运行在这台电脑，地址默认是 http://127.0.0.1:8788，不需要公网服务器。

5. 以后双击程序文件夹里的“启动 FitTrack”快捷方式。
   “停止 FitTrack”用于退出后台，“重启 FitTrack”用于正常重启。
   你可以自己将这些快捷方式复制到桌面。移动程序文件夹后需重新运行 FitTrack.exe 绑定原数据目录。

关于 AI：
每个账号需在“个人设置 → 我的 AI 配置”填写自己的 API Key。
服务地址：https://api.deepseek.com
识图模型、文字模型：deepseek-flash
AI 需要联网和 API 账户额度；本程序不附送 Key，也不使用发布者的 Key。
没有 Key 或暂时断网，仍可手动记录饮食、体重、训练，查看图表和计算热量。
照片分析和 AI 建议都需人工核对。包装标签的“每100克”与“实际吃了多少”要分别确认。

请牢记：
关闭网页不会停止后台；电脑重启后需要再次双击启动快捷方式。
本程序不设置开机自启，不创建 Windows 服务或计划任务。
程序目录与数据目录分开管理；升级程序不要删除数据目录。
备份在设置页手动创建，不会因为每天记录就自动产生独立ZIP备份。
浏览器缓存和 Windows 自身记录由它们各自管理。

遇到问题：
打不开页面：先双击启动快捷方式，再访问本机地址。
端口8788占用：检查是否已有 FitTrack 实例，使用与原数据目录绑定的入口，不要重复启动。
AI失败：检查自己的Key、网络和额度，查看提示后重试或手动补录。
程序来源提示：本版本未做商业代码签名，请从可信的原始发布者获取，并核对随包提供的SHA-256。

更详细的图文说明：双击“首次使用指南.html”。

卸下软件：先停止 FitTrack，再删除程序文件夹及自己创建的快捷方式。
数据是否删除由你决定；保留数据目录即可以后继续使用。
