首次使用指南 · v0.4.0 Windows 本机便携版

无需命令行，也无需安装 Python / Node / Anaconda。这个说明文件可以离线阅读。
第一次启动数据在哪里配置AI每天怎么记备份与升级常见问题

01　第一次启动，只需五步

1完整解压

右键ZIP选择“全部解压”，将整个文件夹放到固定可写位置，例如 D:\Apps\FitTrack。

2双击程序

打开 FitTrack.exe。旁边的 _internal 是运行组件，请一起保留。

3选择数据目录

在Windows选择窗口中选择一个专用空文件夹，例如 D:\我的健身数据。已有有效FitTrack数据目录也能继续使用。

4注册并填写资料

浏览器会自动打开本机页面。注册自己的账号，填写身高、体重、性别、静息能量和目标；体脂可留空。

5保存启动入口

程序文件夹内会生成“启动 / 停止 / 重启 FitTrack”快捷方式。以后用“启动”入口，也可自己将快捷方式复制到桌面。

页面默认地址是 http://127.0.0.1:8788，只供本机使用。关闭网页后后台继续运行；双击“停止”才退出。重启电脑后需手动启动，本程序不设置开机自启。

02　你决定数据放在哪里

程序文件夹保存软件，第一次选择的数据根目录保存账号、加密凭据、健康记录、照片、日志及备份。两者可以位于不同位置。

程序目录
EXE、运行组件、快捷方式↔自选数据根目录
账号、Key、日志与备份→个人健康工作区
体重、饮食、照片与训练

进入“个人设置 → 存储位置与数据管理”可查看具体位置、占用空间、个人目录与备份列表。个人健康工作区可改为根目录内自己的专用子目录。

请勿将数据目录放进程序的 _internal 文件夹。移动程序文件夹后，重新运行EXE并选择原数据根目录来生成新的快捷方式。浏览器缓存和Windows自己的记录由它们各自管理。

03　让AI帮助你，需要自己的Key

每个账号各自配置。程序不附送API Key，也不会使用发布者的个人Key。访问AI时，照片或相应记录会发送给所配置的AI服务。

个人设置 → 我的AI配置

  1. 在DeepSeek官方开放平台申请API账户和Key，保证账户有可用额度：打开DeepSeek开放平台。
  2. 在“我的AI配置”中填写Key，核对上面的服务地址和模型，再保存。ChatGPT Plus订阅不能代替DeepSeek API Key。
  3. 勾选“记住此账号的Key”会加密保存到本机数据目录；不勾选则只在当前登录会话内存中保留，退出或重启后需重新输入。
  4. “测试连接”只检查鉴权；生成照片识别、目标、运动估算或建议时才提交相应请求。
没有Key或断网时，手动饮食、身体记录、训练、图表和热量计算仍可使用。AI结果只是估算，确认前请核对，程序不会自动更改目标和排期。

04　每天怎么记录

身体与目标

在身体记录填写当天体重、可选体脂或静息能量。在设置中填写目标体重，可由AI建议每日热量和营养分配，采用后仍需保存，也可自行填写。

饮食与普通餐食照片

顶部日期决定记录日期，可以选择昨天或更早日期补录。照片可拖入上传区域，填写“鸡蛋只吃蛋白”等说明，分析后编辑名称、份量和营养值，确认才计入摄入。每次新增餐食会累加，不会覆盖同一天已确认的其他餐食。

上传照片与说明→核对AI草稿→确认入账

包装营养标签：标签基准 ≠ 实际份量

选择“包装营养标签”，尽量让营养表正对镜头、避开反光。核对AI读出的“每100克 / 每份 / 整包”、能量单位和三大营养素，再填写实际吃的克数或“每袋重量 × 实际袋数”。缺失字段可以手动填写，不能将未知营养当成零。

例如：能量374 kJ / 每100克

吃60克：53.63 kcal　吃120克：107.27 kcal

“一袋60克”说明袋重；请另外确认吃了几袋。先计算预览，再确认入账。

饮食周视图可翻看历史周，记录不会按周清除。“照片分析记录”的垃圾桶只删除分析任务与结果，保留已入账餐食及照片；删除餐食要点餐食卡片的删除按钮。删除前都有确认，已有备份不受影响。

训练、羽毛球与排期

力量训练填写动作和逐组重量、次数。有氧填写类型、时长、强度和描述，可用AI估计整段平均强度，先预览、采用，再保存入账。训练排期只有转为实际训练才计入消耗。

趋势、每日反馈与每周复盘

首页和趋势页展示体重、体脂、热量及训练变化。每日建议需手动生成，也可以只点“仅完成今日记录”。每周复盘要求该周期已结束，连续七天每天有至少一条已确认餐食并完成记录；休息日也需标记完成，不要求每天称重。

当前统计周期从2026-10-15起划分，每七天一期，首期10/15—10/21在10/22解锁。更早的饮食记录仍可查看和补录；热量消耗与缺口为估计值。

05　备份、换电脑与升级

想做什么怎么操作
备份健康记录设置页点击“创建备份”，ZIP保存到自选根目录的backups目录。备份是手动创建，日常保存记录不等于已有独立备份。
换电脑继续记录将健康ZIP备份带到新电脑，在新账号中导入。健康备份不包含登录密码和API Key，新电脑重新注册和配置自己的Key。
恢复原账号与凭据正常停止程序后，另行备份整个数据根目录；不能只复制运行中的SQLite主文件。恢复完整根目录时需保留secrets主密钥，Windows文件权限也要允许当前用户访问。
升级软件先停止旧版并备份，新版解压到新程序目录，运行新EXE选择原数据根目录，再使用新生成的快捷方式。不要删除数据目录。
移动数据目录使用设置页的个人工作区迁移或本机管理员的根目录迁移。程序会复制、核验、切换并保留旧档，迁移前等待AI任务结束。
主加密密钥丢失后，已有Key密文无法解密，健康记录仍可访问。请恢复完整备份或重新填写个人API Key。

06　常见问题

双击后没有页面？

等待几秒，然后手动访问 http://127.0.0.1:8788。已启动时再次双击会复用同一实例。浏览器后台预启动可能保留无窗口进程，可尝试新建浏览器窗口；无需因为后台有Edge进程就结束全部浏览器。

提示端口被占用、目录找不到或权限不足？

确认使用的是与原根目录绑定的快捷方式、原磁盘已连接、程序目录和数据目录可写。端口冲突不会自动改成另一个地址或另开第二个实例。

AI识别失败，或者读错标签？

检查Key、账户额度、网络和设置的模型。根据提示手动重试，或手动填写标签；重新拍摄清晰营养表也有帮助。不要直接把失败或缺失字段视为零热量。草稿未确认不入账。

软件来源提示或杀毒软件询问？

本版本没有商业代码签名。只从可信发布者获取，并核对SHA-256；如仍被安全软件阻止，联系发布者确认，不要关闭系统防护。

想彻底退出或卸下？

关闭网页后后台仍运行；用“停止FitTrack”或设置页管理员停止入口退出。之后可删除程序文件夹及自己创建的快捷方式。数据目录是否保留或删除，由你决定。
